========================================
SDLC – Software Development Life Cycle
========================================

## What is SDLC?
SDLC (Software Development Life Cycle) is a process used to design, develop, test, and deploy software in a structured way.

---

## Phases of SDLC

### 1) Requirements Gathering
- Collect requirements from clients/stakeholders.
- Understand business needs and goals.

---

### 2) Planning
- Define project scope, timeline, and resources.
- Risk analysis is done here.

---

### 3) Design
- Create system architecture and design.
- Includes:
  - High-Level Design (HLD)
  - Low-Level Design (LLD)

---

### 4) Coding (Development)
- Developers write code based on design.
- Programming languages like Java, Python, etc. are used.

---

### 5) Build
- Convert source code into executable/application.
- Tools like Maven, Gradle are used.

---

### 6) Unit Testing
- Developers test individual components.
- Ensures each module works correctly.

---

### 7) System Integration Testing (SIT)
- Combine modules and test as a complete system.
- Verify interaction between components.

---

### 8) Performance Testing
- Check system speed, scalability, and stability.
- Example: Load testing, stress testing.

---

### 9) Security Testing
- Identify vulnerabilities and security risks.
- Ensure data protection and system safety.

---

### 10) User Acceptance Testing (UAT)
- Done by end users or clients.
- Confirms the system meets business requirements.

---

### 11) Deployment (Production)
- Release the application to production environment.
- Users can start using the system.

---

### 12) Maintenance (Added Phase)
- Fix bugs and improve features.
- Provide updates and support.
